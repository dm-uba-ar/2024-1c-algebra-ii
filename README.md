# Régimen de aprobación

- La materia tiene dos exámenes parciales que serán calificados con un Insuficiente o un aprobado. Ambos parciales contarán con una fecha de recuperación cada uno. Para aprobar los trabajos prácticos ambos exámenes deben ser aprobados. Para aprobar la materia es necesario aprobar los trabajos prácticos y aprobar el examen final. Además es necesario completar la encuesta obligatoria de fin de cuatrimestre.
